## Программа вычисления суммы цифр дробной части вещественного числа

### Назначение программы

Программа предназначена для вычисления суммы цифр, расположенных после десятичного разделителя (запятой или точки) в вещественном числе, введенном пользователем.

Помимо выполнения вычислений программное обеспечение обеспечивает ведение журнала вычислений, создание резервных копий лог-файлов и восстановление данных из ранее созданной резервной копии.

### Возможности программы

Программа позволяет:
- вычислять сумму цифр дробной части вещественного числа;
- обрабатывать ввод чисел через точку и через запятую;
- отображать результаты вычислений в графическом интерфейсе;
- сохранять результаты вычислений в журнал;
- создавать резервные копии журнала вычислений;
- восстанавливать журнал из резервной копии;
- хранить историю выполненных операций.

### Требования к программному обеспечению

Для работы программы необходимы:
- операционная система Windows 10 или выше;
- Python версии 3.10 и выше;
- библиотека Tkinter (входит в стандартную поставку Python).

### Запуск программы

Для запуска программы необходимо выполнить следующие действия:
1. Открыть проект в среде разработки PyCharm.
2. Убедиться в наличии всех файлов проекта.
3. Открыть файл main.py.
4. Нажать кнопку Run.
5. Дождаться открытия главного окна программы.

После запуска пользователю будет доступен графический интерфейс для выполнения вычислений.

### Порядок работы с программой

#### Выполнение вычисления

Для вычисления суммы цифр дробной части числа необходимо:

1. Ввести вещественное число в поле ввода.
2. Нажать кнопку «Вычислить».
3. Ознакомиться с отображенным результатом.

**Пример:**

Введено число:

15,378

Дробная часть:

378

Результат вычисления:

18

#### Создание резервной копии

Для создания резервной копии журнала вычислений необходимо:

1. Запустить программу.
2. Нажать кнопку «Создать резервную копию».
3. Дождаться появления уведомления об успешном выполнении операции.

После выполнения действия файл резервной копии будет сохранен в каталоге backup.

#### Восстановление журнала вычислений

Для восстановления данных необходимо:

1. Нажать кнопку «Восстановить лог».
2. Дождаться завершения процедуры восстановления.
3. Проверить корректность содержимого журнала.

### Обработка ошибок

Если пользователь вводит некорректное значение, программа выводит сообщение об ошибке и предлагает повторить ввод.

Примеры некорректных данных:

- abc
- число12
- 12,34,56

В подобных случаях вычисление выполняться не будет.

### Хранение данных

Результаты вычислений автоматически записываются в файл журнала.

Каждая запись содержит:
- дату выполнения операции;
- время вычисления;
- исходное число;
- результат вычисления.

### Завершение работы

Для завершения работы необходимо закрыть главное окно программы стандартными средствами операционной системы.

Все сохраненные данные останутся доступными для последующего использования.
